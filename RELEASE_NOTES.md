# EchelDraw 0.1.5

The next-step picker follows your favorite types. Drawings, settings and
personal libraries from 0.1.4 remain compatible; the plugin ID remains `eddraw`.

Next-step picker ("Próxima etapa"):

- The first page shows exactly the favorite types chosen in the flow
  preferences, in their order. A type you remove from the favorites no longer
  appears there.
- "Mais tipos" (more types) lists every other type, so no type becomes
  unreachable, even when all five favorites come from the second page.
- "Mesmo tipo" (same type) can be turned off in the preferences like the other
  types.
- The number shortcuts follow the same pages.

Install or update with BRAT using `EchelOneZero/echeldraw-obsidian`, or download
`echeldraw-0.1.5.zip` and copy its three files into the existing plugin folder.
When updating manually, preserve `data.json`, `personal-library.json` and
recovery files.

Requires Obsidian desktop 1.13.7 or later.
